# 豆包视频水印去除

使用 `scripts/remove_watermark.py`，不要凭经验硬编码时间段。

## 工作流

1. 用 `ffprobe` 获取宽高、帧率、时长。
2. 每 0.25–0.5 秒抽一帧并生成接触表，检查水印在哪个角、何时出现或切换。
3. 若用户已给出准确时段，优先采用；边界向前后各扩 0.15–0.25 秒，防止淡入淡出残字。
4. 根据原始 720×1280 坐标缩放区域：
   - 左上角参考区：`x=1,y=1,w=310,h=145`
   - 右下角参考区：`x=500,y=1170,w=215,h=100`
   先检查原帧；文字超出时扩大区域，不要仅覆盖图标。
5. 用脚本按时段执行 FFmpeg `delogo`。只处理水印存在的时段，水印不存在时保持原画面。
6. 至少抽查每个时段的开始、中间、结束以及切换边界。发现单字残留（常见“成”字）就扩大区域或修正时段后重做。
7. 输出到 `/var/minis/attachments/`，用内嵌视频链接交付。

## 命令

```sh
python3 scripts/remove_watermark.py INPUT OUTPUT \
  --top-left 3.8-8.15 \
  --bottom-right 0.8-4.15,7.8-10.1
```

时间单位为秒，可传多个逗号分隔区间。脚本会按视频分辨率自动缩放修复框。

## 质量原则

- 始终从原视频重新编码，不在已处理成片上叠加二次处理。
- 默认 `libx264 -crf 18 -preset medium`，音频 AAC 192k，并启用 faststart。
- `delogo` 是邻域插值，复杂运动背景可能轻微模糊；缩小处理范围和限定时间比全程处理更重要。
- 不确定时先生成检查帧，不要声称已彻底去除而未复查。
